# MatrixClaimed

A Vite + React property opportunity dashboard for exploring fictional distressed-property listings in Los Angeles. The dashboard includes search, distressed status, price, bedroom, and opportunity score filters, sorting, grid/list views, and saved properties.

> All property information, addresses, prices, and metrics in the app are illustrative demo data, not real listings or investment advice.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.
